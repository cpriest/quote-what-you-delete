# Quote What You Delete

*"Quote what you delete."*

Minnesota's November 2026 ballot asks voters to amend the constitution's Permanent School Fund clause. The ballot question describes a benefit. It does not mention that the amendment deletes 76 words from Article XI, Section 8, including the sentence "The principal of the permanent school fund shall be perpetual and inviolate forever."

This project is not a campaign for or against that amendment. It exists to make this class of concealment structurally impossible, with a one-sentence rule:

> Any ballot question proposing to amend the Minnesota Constitution that would delete or modify existing constitutional language must quote that language verbatim in the question as it appears on the ballot.

## Layout

- `site/` — the website (static, no build step; deployed via Cloudflare Pages with build output directory `site`)
- `exhibit/` — the side-by-side exhibit: source, shareable PNG, and the verification notes for every quoted word
- `rule/` — the rule drafted as an introduceable bill (proposed Minn. Stat. §204D.151), with worked example and drafting notes
- `scorecard/` — six transparency criteria applied to every Minnesota constitutional ballot question, HF 3900 first
- `outreach/` — the candidate one-pager

## Verification

Every quotation in these materials was checked verbatim against primary sources on revisor.mn.gov: HF 3900, 3rd Engrossment (2026); the Minnesota Constitution; and the proposing session laws of the historical amendments scored on the scorecard. `exhibit/README.md` documents the checks. If you find an error, say so: hello@quotewhatyoudelete.org — corrections get published, including against ourselves.
